Super Agent (super-agent.com) combines auto-clicking reject buttons with sending the GPC signal — mechanically, a similar idea to what BannerBye and Consent-O-Matic do. It has around 4,300 users and a 3.6 rating on the Chrome Web Store.

The difference isn't the mechanism. It's what sits underneath it: Super Agent is closed source, runs on a paid subscription, and according to its own privacy policy collects anonymous usage statistics. For a tool whose entire premise is protecting your privacy, that combination is worth pausing on.

The honest take

Sending GPC and auto-clicking reject is a solid mechanism — Super Agent gets the fundamentals right on that front. What undermines the pitch is trust: you're asked to install something with broad access to every page you visit, run by a company you can't inspect the code of, that collects usage data by its own admission, and that charges a recurring fee for the privilege.

That's not a technical criticism, it's a structural one. A privacy tool asking you to trust it on faith is a harder sell than one that shows its work. BannerBye's entire codebase is public, the extension sends nothing home except what you explicitly report, and the core product stays free — because charging a subscription for "trust us" isn't a model that fits a tool built to reduce, not add to, what you have to take on faith online.

Questions about this comparison

Is Super Agent open source?

No. Super Agent is closed source, so there is no way to independently verify what the extension does with the page access it requests.

BannerBye's full source code is public on GitHub — every rule and every line can be audited or forked.

Does Super Agent collect data?

According to its own privacy policy, Super Agent collects anonymous usage statistics. That may be limited in practice, but it can't be independently verified without access to the source.

BannerBye sends zero telemetry: nothing about your browsing leaves your device, except the hostname you explicitly submit through "Report broken site."

Is Super Agent free?

No, Super Agent runs on a paid subscription model.

BannerBye is free on Chrome, Firefox and Edge, with a one-time purchase for the Safari version on iPhone, iPad and Mac, reflecting Apple's App Store distribution model rather than a recurring fee.
